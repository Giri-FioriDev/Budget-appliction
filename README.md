# 📊 50/30/20 Budget Tracker

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Click%20Here-success?style=for-the-badge&logo=github)](https://giri-fioridev.github.io/Budget-appliction/)

A modern, mobile-first Progressive Web Application (PWA) designed to help you track expenses and manage personal finances using the **50/30/20 budgeting framework**. Featuring a sleek, GitHub-inspired dark theme, this application runs entirely in your browser and stores data locally for absolute privacy.

## ✨ Key Features

*   **50/30/20 Budget Engine:** Input your net income, and the app automatically calculates your spending limits across Needs (50%), Wants (30%), and Savings (20%).
*   **Dynamic Visualizations:** An integrated, interactive Chart.js doughnut chart provides a real-time visual breakdown of your spending distribution.
*   **Installable PWA:** Fully configured with a Web App Manifest and Service Worker, allowing you to install the app on iOS or Android for a native, full-screen offline experience.
*   **100% Private & Local:** All transaction data is saved strictly to your device's browser `localStorage`. No external databases, no tracking.
*   **Frictionless Exports:**
    *   **Copy for Sheets:** Instantly aggregates your category totals to your clipboard, perfectly formatted to paste into Google Sheets or Excel.
    *   **Download CSV:** Export your complete raw transaction history for external backups.

## 🛠️ Technology Stack

*   **Frontend:** HTML5, CSS3 (Custom GitHub Dark Theme)
*   **Logic:** Vanilla JavaScript (ES6+)
*   **Data Visualization:** Chart.js (via CDN)
*   **Architecture:** Progressive Web App (PWA)

## 📱 How to Install on Mobile

Because this is a Progressive Web App, you can install it directly from your browser without using an app store:

1. Open the [live link](https://giri-fioridev.github.io/Budget-appliction/) in your mobile browser (Safari for iOS, Chrome for Android).
2. **iOS (Safari):** Tap the **Share** icon at the bottom of the screen, scroll down, and tap **"Add to Home Screen"**.
3. **Android (Chrome):** Wait for the automatic **"Install App"** prompt at the bottom of the screen, or tap the browser's 3-dot menu and select **"Add to Home screen"**.
